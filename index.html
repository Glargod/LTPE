LTPE

Line-of-Sight Teleport Priority-Guided Escape
A sparse, goal-directed exploration algorithm for confined organic & hybrid spaces

Executive Summary

In unknown 3D voids — caves, mines, lava tubes, asteroid structures — the overriding goal is usually escape to safety (surface, fresh air, refuge) rather than exhaustive mapping or shortest-path optimality.

LTPE achieves this efficiently by:

  • Scanning hubs to discover visible features
  • Low-cost jumps to promising points (LOS teleport abstraction)
  • Rapid dead-end pruning
  • Retroactive priority reinforcement on rich discoveries
  • Probabilistic selection to escape local optima
  • Layered handling of hybrid environments (natural ↔ engineered transitions)

Simulation on modeled ant-nest structures: \~120–150 steps to exit (with stochastic selection) vs. 400–800+ for classic backtracking methods.

Problem & Motivation

Target domains include cave SAR, mining accidents, asteroid/lunar voids, collapsed structures — environments with:

  • Irregular, organic geometry
  • Limited visibility & sensing
  • High cost of backtracking or exhaustive coverage
  • Survival-critical objective: any safe path out > optimal path > full map

Classic methods (BFS/A*, wall-following, full SLAM) struggle with voxel explosion, dead-end penalties, or compute overhead in such settings.

Biological Inspiration

Fire ant colonies (visualized via aluminum casts) reveal hub-centric scanning, quick dead-end rejection, and reinforcement of promising paths — behaviors LTPE emulates.

Real nests are spongy, chamber-heavy, with curves and stubs — perfect for sparse LOS exploration.

LTPE Algorithm

Core Structures

  • Nodes: scan points with (x,y,z)
  • Exif entries: [az, el, dist, pri (0–15), status, origin_id]
  • Queue: per-layer FIFO + probabilistic selection

Actions & Costs

  • Scan: −1 per visible direction discovered
  • Teleport/jump: +1 (abstract LOS); optional +distance modifier for realism
  • Arrival → mandatory scan (even dead-end)

Dead-End Pruning

Only reversal visible → scratch entry (O(1) cost)

Priority (Formalized)

pri = w₁·elevation + w₂·airflow_gradient + w₃·width_estimate + w₄·branch_potential + ...

Weights tunable; airflow gradient often dominant for exit detection.

Probabilistic Queue Selection (Anti-Local-Optima)

Instead of greedy/FIFO only:

P(node_i) = (pri_i + decay_bonus_i) / Σ(pri + decay_bonus)
decay_bonus_i += k × waiting_time   // uncertainty decay

Strong bias to good paths + guaranteed probing of alternatives.

Hybrid Environments & Source-Design Transitions

When scan detects clear shift (scale, regularity, material, branching pattern):

  • Create Transition Node — shared between layers
  • Spawn independent Layer B queue (new fabric)
  • Transition node = exit candidate in Layer A, origin/hub in Layer B
  • Each layer has own: exif queue, pri weights, costs, mode (exifil/escape or explore/map)
  • Cross-layer LOS jumps allowed as bridges/shortcuts

Layer A (natural cave) Transition Node Layer B (mine/engineered) ────────────────► [boundary hub] ◄─────────────── exit candidate new origin / hub (prune if resolved) (full scan → new exif)

Examples: cave → mine drift, ant nest → mole burrow, lava tube → ancient quarry.

Optional Modes per Layer

Exifil/Escape Mode — aggressive pruning, strong exit bias
Explore/Map Mode — keep-all, systematic coverage, documentation

Simulation Results (Preliminary)

Average modeled nest (\~60 segments, \~20 chambers):

  • LTPE + stochastic selection: \~120–150 steps to exit
  • Classic DFS: 400–800+
  • BFS/flood: 300–600+

Needs: 1000+ trials, varied branching/LOS, noise models.

Applications

  • Cave SAR: handheld LiDAR/AR device
  • Mining: helmet with gas sensors for pri
  • Space: rover in lava tubes, depth-to-surface proxy

Advantages & Limitations

AdvantagesLimitations
  • Low visited fraction (\~20–50%)
  • Rapid dead-end rejection
  • Handles hybrid voids via layers
  • Probabilistic escape from traps
  • Explainable & low compute
  • No shortest-path guarantee
  • Pri tuning required
  • Assumes usable LOS sensing
