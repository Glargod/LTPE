LTPE

Line-of-Sight Priority-Guided Escape
LTPE is a sparse, goal-biased exploration algorithm designed to minimize steps to exit in irregular 3D environments where mapping is secondary to survival.

Executive Summary

In unknown confined 3D voids (caves, mines, lava tubes, asteroid structures), the overriding objective is usually any safe path to exit — not shortest path or full map.

LTPE achieves this with:

  • Hub scanning + low-cost LOS relocation
  • Rapid dead-end pruning (O(1) cost)
  • Retroactive priority reinforcement on rich discoveries
  • Probabilistic queue selection (weighted lottery + uncertainty decay + occasional random pull)
  • Independent layers for source-design transitions (e.g. cave → mine drift)

Illustrative reasoning on representative ant-nest topologies: ≈120–150 steps to exit vs. 400–800+ for classic DFS backtracking.

Illustrative Reasoning on Representative Topologies

Step estimates are derived from probabilistic reasoning on branching tunnel graphs inspired by observed fire-ant nest topology (≈60 segments, ≈20 chambers, branch factor 2–5).

  • Classic DFS backtracking: typically 400–800+ steps (full traversal + return costs)
  • LTPE with probabilistic selection: ≈120–150 steps (analytic estimate)

These are illustrative — based on expected wasted traversal under different pruning/reinforcement behaviors — rather than full Monte-Carlo simulation results. Future work includes 1000+ randomized trials with varied LOS range and noise.

The algorithm favors nodes with high directional entropy (many unexplored exits), which statistically increases the probability of reaching an exit earlier in irregular tunnel graphs.

LTPE Algorithm

Core Structures

  • Nodes: scan points with (x,y,z)
  • Exif entries: [az, el, dist, pri (0–15), status, origin_id]
  • Queue: per-layer FIFO + probabilistic selection

Actions & Costs

  • Scan: −1 per visible direction discovered
  • LOS relocation: direct travel to visible node (cost ≈1 step for algorithmic simplicity; optional +distance modifier for physical realism)
  • Arrival → mandatory scan (even dead-end)

Dead-End Pruning

Only reversal visible → scratch entry

Priority (Formalized)

pri = w₁·elevation + w₂·airflow_gradient + w₃·width_estimate + w₄·branch_potential + ...

Probabilistic Queue Selection

// Weighted lottery
P(node_i) = (pri_i + decay_bonus_i) / Σ(all unfinished pri + bonuses)
decay_bonus_i += k × steps_since_last_pull   // k ≈ 0.1–0.5

// Anti-trap entropy boost (recommended)
with probability ε (0.05–0.10) per decision:
    select random unfinished entry

This small randomness prevents lock-in on suboptimal paths (e.g. long spirals) and is common in real autonomous cave robots and MCTS variants.
